Hi lemons4all,

I'm working on SAO++ (https://github.com/holdTheDoorHoid/sao-plus-plus), an open project that takes classic
add-ons and updates them to the 6-pin SAO v1.69bis header with a shared set of parts, so they can be built
again in quantity.

I've done ports of your three DEF CON 26 add-ons (RBG SAO, Frida SAO and LSP SAO) from the KiCad files on your
hackaday.io pages. Your art and outlines are kept, with a surface-mount 6-pin header, a SAO/OFF/battery switch
and a CR2032 clip added on the back. The through-hole LEDs are replaced by surface-mount ones that shine through
the board from behind, so the LED holes on the front are gone; each board's README lists exactly what changed.
They are in the repo now, marked "permission pending, not open-licensed", credited to you as lemons4all. I should
have asked first; if you want any of them changed or taken down, say so and it's done.

1. May the updated design files stay published in the SAO++ repo under CERN-OHL-S (hardware) and CC-BY-SA (art)?
   If you'd prefer a different license, tell me which.

   @mrtwinkletwink, which I've kept.

Happy to send renders or finished boards. Thanks for making them.
