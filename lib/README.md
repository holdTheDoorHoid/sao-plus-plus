# Shared library

Everything a board needs that is not specific to its art. Boards reference these by **project-relative path** (`${KIPRJMOD}/../../../lib/...`) so a fresh clone works with no setup.

| Path | Contents | Status |
|---|---|---|
| `sao-plus-plus.kicad_sym` | Symbols for the connector, power switch, cell clip, through-board LED (red and white) and LED resistor, each carrying its `SAOPP_ID`, MPN and distributor numbers so BOM exports are ready to order. Generated by `tools/saopp_symbols.py` | built; side-firing LED symbol to add |
| `sao-plus-plus.pretty/` | Footprints for CONN-01, SW-01, BAT-01, LED-10 (through-board) and the 0603 resistor, drawn from the manufacturer drawings. Generated by `tools/gen_footprints.py` | built, **not yet proven on a physical board**; side-firing LED (LTST-S270) and BAT-02 to add |
| `3dmodels/` | STEP models for 3D checks | to build |
| `blocks/` | The power-select circuit as a reusable schematic sheet | to build (for now it is written out in each board's `circuit.json`) |
| `template/` | Starter KiCad 10 project | to build |

How a board is made today: write `boards/<slug>/hardware/circuit.json` (which part, which pin on which net), run `python3 tools/gen_schematic.py <slug>` for the schematic, and lay out the board against the same file with a `build_board.py` that imports the shared helpers in `tools/saopp_board.py`. `boards/mad-cat/hardware/` is the worked example to copy (Fat Pika's script came first and carries its own copies of the helpers).

One footprint can serve several parts: the through-board LED footprint is used for red (LED-10) and white (LED-11). The symbol chosen in `circuit.json` decides the part number that lands in the BOM.

Rules:
- Footprints come from the manufacturer's drawing, never from a guess. Write the drawing's URL in the footprint description.
- Change a shared footprint only by adding a new revision (`_v2`); boards already built must not silently move.
